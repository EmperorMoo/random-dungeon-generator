Random Dungeon Generator for D&D

I tried to make it as user friendly as possible so just customize and enter whatever you want.


Features:

    Choose a custom dungeon name or generate a random one.

    Choose a specific number of rooms or let the generator randomly select 3–8 rooms.

    Customize monster types.

    Set minimum and maximum monsters per room.

    Customize treasure types.

    Set minimum and maximum treasures per room.

    Choose a dungeon difficulty.

    Customize trap types.

How to Use:

    Open the website.

    Enter your dungeon settings.

    Leave optional number fields blank to allow random generation.

    Click Generate Dungeon.

    Explore your randomly generated dungeon!
